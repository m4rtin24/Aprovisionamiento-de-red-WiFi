| Método | URL        | Descripción                                                |
| ------ | ---------- | ---------------------------------------------------------- |
| GET    | `/`        | Muestra la interfaz web de configuración                   |
| POST   | `/guardar` | Guarda el SSID y la contraseña enviados por el usuario     |
| GET    | `/status`  | Devuelve el estado actual de conexión del ESP32            |
| POST   | `/reset`   | Borra las credenciales guardadas y reinicia el dispositivo |
